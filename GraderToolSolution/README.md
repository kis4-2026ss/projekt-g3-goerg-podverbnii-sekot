# GraderTool

Leere Visual-Studio-Solution für eine C# + Avalonia UI Desktop-App.

## Projekte

- `GraderTool.App` - Avalonia UI und ViewModels
- `GraderTool.Core` - Workflows, Models, Interfaces und Validierung
- `GraderTool.Infrastructure` - Dateisystem, Git, Pfade, Settings und Logs
- `GraderTool.GitHub` - GitHub API, Classroom, Pull Requests und Reviews
- `GraderTool.Ai` - KI-Review-Client, Prompting, Parsing und Normalisierung
- `GraderTool.Tests` - Tests

Noch keine eigenen `.cs`-Dateien enthalten.
